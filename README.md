# Застосунок «Облік ТСЦ» для Android (PWA)

Вебзастосунок, який ставиться на головний екран телефона. Дані зберігаються **лише зашифрованими** (AES-256-GCM),
працює без інтернету. Інтернет потрібен тільки для першого завантаження застосунку та передавання файлів.

## Файли
`index.html`, `app.js`, `core.js`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`.
У цих файлах **немає ваших даних і паролів** — їх можна безпечно розміщувати на хостингу.

## 1. Розміщення (одноразово). Варіант: GitHub Pages (безкоштовно)
Умова: безкоштовний GitHub Pages працює з **публічними** репозиторіями (код видно всім, даних у ньому немає).
1. Створіть обліковий запис на github.com.
2. New repository → назва, наприклад, `tsc-app` → Public → Create repository.
3. «uploading an existing file» → перетягніть **усі файли з цієї папки** → Commit changes.
4. Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 хвилини адреса буде такою: `https://ВАШ_ЛОГІН.github.io/tsc-app/`.
Назви кнопок на GitHub можуть трохи відрізнятися.

## 2. Встановлення на телефон
1. Відкрийте адресу в Chrome на Android.
2. Меню ⋮ → «Встановити застосунок» (або «Додати на головний екран»).
3. Запустіть із головного екрана. Перше відкриття — з інтернетом.

## 3. Робота
1. На ПК: `Експорт_для_телефона.bat` → файл `tsc_для_телефона.enc` → покладіть у хмару (Google Drive / OneDrive).
2. На телефоні: «Відкрити пакет (.enc)» → оберіть файл (вибирач файлів Android показує і хмарні диски) → введіть пароль.
3. Три вкладки: **Пристрої**, **Співробітники**, **Довідники**.
   - *Пристрої*: оберіть ТСЦ; пошук іде по всіх ТСЦ. Якщо знайдено співробітника, він показується над пристроями; торкніться його, щоб побачити його пристрої. «Вільно» = вільна адреса.
   - *Співробітники*: пошук, картка співробітника з усіма його пристроями (телефон і пошта натискні), «+ Додати співробітника», редагування, видалення (неможливе, поки за співробітником є пристрої).
   - *Довідники*: типи обладнання, типи ОС, виробники, відділи — додавати, перейменувати (з оновленням усіх записів, що на них посилаються), видаляти (лише невикористані). Довідник ТСЦ — лише перегляд.
4. «Відділ», «Телефон», «ТСЦ(РСЦ)» підтягуються з довідника користувачів і не редагуються.
5. Обов'язкові поля, якщо запис заповнено: Ім'я обладнання, Тип обладнання, Статус.
6. «Зміни: N» → «Поділитися…» (оберіть Диск/OneDrive) або «Зберегти файл» → файл `зміни_….enc`.
7. На ПК: завантажте файл, `Імпорт_змін_з_телефона.bat`, введіть пароль.
8. Після імпорту знову зробіть експорт на телефон (крок 1), щоб на телефоні були актуальні дані.

## Сканування штрих-коду (інвентарний номер)
- У формі пристрою біля поля «Інвентарний номер» є кнопка **📷**: наведіть камеру на штрих-код наклейки. Прочитаний номер показується для перевірки (його можна виправити) і вставляється в поле після «Використати».
- У вкладці «Пристрої» кнопка **📷** поруч із пошуком шукає пристрій за номером: якщо знайдено один, його форма відкривається одразу.
- Якщо такий номер уже вказано в іншому пристрої, застосунок попередить.
- Є ліхтарик (якщо його підтримує камера) і ручне введення, якщо код не читається.
- Розпізнаються Code 128, Code 39, Code 93, Codabar, EAN-13/8, UPC, ITF, QR і Data Matrix. Спершу використовується вбудований розпізнавач Chrome, інакше — бібліотека ZXing (Apache-2.0, файл `zxing-LICENSE.txt`).
- Кадри з камери обробляються лише на телефоні й нікуди не передаються. Камера вимикається при закритті сканера або згортанні застосунку.
- При першому скануванні Android запитає дозвіл на камеру. Якщо відмовили: Налаштування Android → Застосунки → Chrome → Дозволи → Камера.
- Друкований текст наклейки (без штрих-коду) не розпізнається: це потребує важкої бібліотеки розпізнавання тексту.

## Безпека
- Пароль не зберігається ніде; без нього дані не відновити.
- Через 2 хв у фоні застосунок блокується; дані в пам'яті стираються.
- Поле «Пароль» обладнання на телефон не передається, якщо не ввімкнути `--with-passwords` на ПК.
- «Забув пароль / стерти дані» видаляє локальну копію й неекспортовані зміни.

## Обмеження
- Не синхронізація в реальному часі: обмін файлами вручну.
- Не змінюйте на ПК ті самі записи, поки зміни з телефона не імпортовано (конфлікти виявляються, але не зливаються).
- Якщо «Поділитися…» не пропонує диск, використайте «Зберегти файл» і перенесіть його вручну.
- Очищення даних браузера в налаштуваннях Android видаляє локальну копію: тримайте пакет у хмарі.

## Оновлення застосунку на GitHub (після нової версії)
1. У репозиторії: Add file → Upload files → перетягніть **усі файли** з нової версії (файли з тими самими назвами замінять старі) → Commit changes.
2. Зачекайте 1–2 хвилини. На телефоні відкрийте застосунок **двічі** (перший раз завантажується нова версія, другий — вона запускається).
3. Версія 3 відкриває лише пакети, створені `tsc_sync.py` версії 3 (поле «Ім'я користувача» перейменовано на «Інвентарний номер»). Зробіть новий експорт на ПК. Дані на телефоні від версії 1 потрібно стерти («Забув пароль / стерти дані») і відкрити новий пакет; неекспортовані зміни з версії 1 спершу експортуйте й імпортуйте на ПК.
